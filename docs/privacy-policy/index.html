HCloud Control Privacy Policy

Effective date: 14 October 2026

HCloud Control is an independent Android application for managing Hetzner Cloud resources. It is not affiliated with Hetzner.

Data the app handles

The app asks you to enter a separate Hetzner Cloud API token for each Cloud project you choose to connect. If you use Object Storage, it also asks for an S3 access key and secret key. It processes resource metadata returned by connected services, including server names, IP addresses, locations, storage names, network configuration, DNS data and SSH-key metadata. A one-time root password may be displayed after server creation if Hetzner returns one.

How data is used and stored

Cloud tokens and Object Storage credentials are used only to authenticate requests to the Hetzner service you selected. They are stored encrypted on your device using Android Keystore-backed encryption. Resource metadata is held in memory to display the active screen.

The app does not operate an application backend, synchronize credentials, sell data, use advertising, or include analytics or crash-reporting SDKs. It does not intentionally write API tokens, Object Storage secrets or one-time root passwords to its diagnostics. A root password is displayed only in the immediate successful creation flow and is not stored by the app.

Sharing

The app sends requests directly from your device to the Hetzner endpoints required by the features you use. It does not otherwise share your information with third parties.

Your choices

You can remove a configured Cloud project in the app. Removing it removes the corresponding locally stored token and connection metadata. You can revoke a token through Hetzner Cloud at any time. Android system backups are disabled for this app.

Security

No storage or transmission method is completely secure. Keep your device secure, use distinct limited-scope credentials where available, and revoke a credential if you believe your device has been compromised.

Changes

This policy may be updated when the app changes. The effective date above will be updated with a new published version.

Contact

For privacy questions or requests, use the project’s GitHub issue tracker. Do not include API tokens, passwords, access keys, secret keys or other credentials in an issue.

The Android app and this policy are maintained as an open-source project. The source and release notes are available in the linked repository.
